# MailRules handoff

Everything designed so far, ready to drop into a new monorepo.

1. `git init mailrules`, then copy `CLAUDE.md` and `docs/` into it.
2. Open Claude Code in the repo and start with: "Implement milestone M0 from docs/backend-plan.md."
3. Run one milestone per session (M0 → M10). The frontend can start once M1 publishes `api/openapi.yaml`.

Contents
- `CLAUDE.md`: project rules Claude Code loads automatically
- `docs/prd.md` + `prd.pdf`: PRD (the PDF includes the diagrams)
- `docs/backend-plan.md` + `backend-plan.pdf`: backend build plan with milestones
- `docs/design/prototype.dc.html`, `canvas.json`: UI prototype source
- `docs/design/README.md`: screen list and design tokens
